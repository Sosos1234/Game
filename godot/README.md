# Godot Version

This folder contains a Godot 4.2+ prototype of the game.

## Open in Godot

1. Launch Godot.
2. Click **Import**.
3. Select `project.godot` from this folder.
4. Press **Play**.

## Gameplay rules

- Party has exactly 3 heroes.
- Each room gives 5 cards:
  - 2 event cards
  - 3 monster cards
- You must play exactly 2 cards per room.

## Controls

- `1..5` - select/unselect card
- `Enter` - play selected cards
